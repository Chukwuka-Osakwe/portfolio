## The ask

"Build us a component library." Three teams, three button styles, endless
drift. The instinct was to start drawing components.

## The decision

I argued for **foundations first**: color, type, and spacing as tokens, plus a
shared vocabulary for how we name and talk about them. Components without a
token layer just encode today's inconsistencies in reusable form.

## How it went

- Tokens shipped as the single source of truth.
- Components were assembled *from* tokens, so a palette change propagated everywhere.
- The naming work paid off most — shared language reduced design-review friction.

## Outcome

The library became something teams trusted rather than worked around. **Systems
are agreements first, code second.**
